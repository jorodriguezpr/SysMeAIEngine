Knowledge Graph

Extracts entities and relations (triples) from your ingested documents with the cloud provider — one API call per indexed chunk — and stores them in a local SQLite graph. Chat grounding (Settings) merges these facts into the retrieved context, so questions like "who is X and what did he do?" can be answered by traversing knowledge, not just finding look-alike passages. Builds are resumable: chunks already in the graph are skipped on rebuild.
