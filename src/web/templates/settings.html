Settings

Chat grounding (answer from your documents)

Grounded mode retrieves passages from your ingested documents (RAG indexes + knowledge graph) before generating, so chat answers come from your actual documents instead of the model's weights. This is the fix for "the model can't answer from my books". Plain mode is the old weights-only behavior. Retrieval upgrades: multi-query rewrites the question several ways (needs the cloud provider enabled below), parent-child widens each hit to its surrounding passage, and the knowledge graph adds entity/relation facts (build a graph on the Knowledge Graph page).

Cloud AI provider

Optional: route chat/RAG generation to a cloud AI provider instead of the local model. When enabled, the Chat page's "Use cloud AI provider" checkbox (and any API caller passing use_cloud: true) uses this here — for RAG chat, local retrieval still happens exactly as before, only the final answer gets written by the cloud model instead of the local one. Keys are stored locally in plain text on this machine, same as this engine's other local settings (registry.json, ENGINE_API_KEY) -- do not use this on a shared or multi-user machine without understanding that.
